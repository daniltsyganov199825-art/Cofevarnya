Как получить бесплатный ключ
  1. На компьютере открой aistudio.google.com и войди под Google-аккаунтом. Из России сайт открывается только через VPN.
  2. Слева внизу нажми «Get API key», потом «Create API key».
  3. Скопируй ключ (начинается с AIza или AQ.), вставь в поле выше и нажми «Сохранить ключ».
VPN нужен только для получения ключа. Дальше запросы идут с серверов Google, где работает твой скрипт, и всё работает без VPN. Ключ хранится в скрипте таблицы, на планшет он не попадает. Бесплатного лимита Google хватает с запасом.

Параметры расчётов

Объём «*» — для любого размера, без стакана (эспрессо). Стакан и крышка к остальным напиткам добавляются сами. Единицы: г, кг, мл, л, шт.
Сиропы из меню считаются сами (как «Сироп ваниль»).

Меню для всех устройств

По одной позиции в строке. После сохранения планшет подтянет меню, когда будет в сети.
Категории «Сиропы» и «Напитки» добавляются сами из меню.
